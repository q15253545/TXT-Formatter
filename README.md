# TXT 排版工具

智慧辨識章節、整理純文字小說的排版工具（PySide6 介面）。純邏輯（章節辨識、
廣告掃描、換行整理…）放在 `core/`，介面放在 `ui_qt/`。

## 下載

到 [Releases](../../releases) 下載 `txt-tool.exe`（頁面上顯示為「TXT排版工具.exe」），雙擊就能執行，不需要安裝 Python。
（沒有數位簽章，第一次開啟時 Windows 可能顯示「已保護您的電腦」，按「其他資訊」→「仍要執行」。）

設定存放在 `%LOCALAPPDATA%\TXTFormatter`：自訂章節規則（`chapter_rules.json`）、
排版設定與選單狀態（`ui_state.json`）、視窗大小（`window.json`）、執行記錄（`logs/`）。
換新版 exe 或搬動 exe 位置，設定都會保留；原始碼版與 exe 版共用同一份。

## 功能

> 截圖中的小說《青雲劍錄》是示範用的自編內容。

### 自動辨識章節、一鍵排版

![主畫面：一鍵排版後的本文與目錄](docs/screenshots/01-main.png)

- 開檔自動偵測編碼（UTF-8、Big5、GB18030…），從檔名取出書名與作者。開檔、匯出都從上次的資料夾開始
  （還沒匯出過就放在原檔旁邊）。匯出成有 BOM 的 UTF-8，Windows 檔案總管的預覽不會變成亂碼。
- 自動辨識卷、章、番外、序章等標題，建立可摺疊的目錄；點目錄直接跳到那一章，
  本文上方顯示目前所在的卷／章。
- 「一鍵排版」套用常用組合：刪除多餘空行、段首縮排、章節前後空行、標題編號與章名之間的間隔。
- 檔名列的問號「說明」：章節標記、本文字色的意思，設定檔所在的資料夾（點路徑打開）與「還原預設」
  （辨識章節的組合、排版設定、開關、視窗大小都還原，程式帶著目前的檔案重新開啟）。
- 各功能視窗最上面一行寫這個視窗找什麼、做什麼。
- 「書籍資料」自動填入最新卷／章與連載狀態，匯出時組成檔名，
  例如「《青雲劍錄》【更新至第2卷第6章+番外】作者：林小舟.txt」、完結時「《書名》（完結）作者：某某.txt」。
- 「匯出 TXT」旁邊的箭頭設定匯出檔名：連載中、已完結各一個格式，按鈕插入變數
  （{title} 書名、{author} 作者、{volume} 最新卷、{chapter} 最新章、{extra} 番外、{extra_count} 番外章數、
  {volume_count} 卷數、{status} 連載狀態），例如「【更新至[第{volume}卷]第{chapter}章】」；
  [ ] 括起來的段落，裡面的變數沒有值時整段省略。下面即時顯示匯出時的檔名，也可以選檔名轉繁體或簡體。
- 所有修改都可以 Ctrl+Z 復原。

### 排版設定

![排版設定面板](docs/screenshots/02-options.png)

- 逐項開關：刪除所有空行、章節間／標題前後／段落間插入空行、整理段落換行（固定字數斷開的段落接回同一行；對話引號沒關又停在字中間的行也接）、
  刪除多餘空格、增加／去除縮排、對話框引號格式化。切換開關時，左下角狀態列會說明這個開關做什麼。
- 章節編號改成中文數字或阿拉伯數字、編號與標題的間隔（半形／全形空格、冒號）、
  標點符號與數字轉全形或半形。
- 「套用到一鍵排版」：把目前的開關與下拉存成工具列「一鍵排版」的組合。
- 「套用格式到選取章節」只排目錄選取的章；「套用格式到全文」排整份。

### 章節管理與主題

![深色模式與章節管理](docs/screenshots/03-dark.png)

- 辨識章節、新增章節、自訂章節規則、合併重複章節（相鄰、章號相同的章節）、缺章檢查（找出跳號的章節）。
  缺章與重複照本文順序列出；原文裡有、只是沒被認成章節的，會註明在哪一行、為什麼
  （例如標題以句號結尾、寫法是「1. 標題」但辨識章節裡沒有這種組合）。
  章號寫法不一致（「一一零一」可能是 1101 也可能是 111）時，照前後章判斷。
  目錄只顯示章號／完整標題，用目錄卡片標題列的開關切換。
- 「自動合併下行標題」：只有章號的標題（「第1章」）把下一行的章名接上來。開關只是預覽：
  目錄和本文用非原文內容的顏色顯示合併後的樣子，本文不改；按「套用到本文」才寫入。
- 「自動合併重複標題」：同一章的標題連續出現兩次、中間只隔幾行（不到 100 字）時只留第一個，
  後面那一行在本文畫刪除線；按「套用到本文」才刪掉。（上）（下）分開的章不算重複。
- 「自動補齊卷號」「自動補齊卷名」：本文沒寫卷標題時，從卷結尾行或章號重新起算推出缺少的卷，先在目錄上預覽；卷結尾行有寫卷名時一起補上。確認後按「套用到本文」才寫進本文。
- 每章標題前面都帶著卷（「卷一 卷名 第N章」）時：只開「自動補齊卷號」，目錄照卷號補上「第一卷」；再開「自動補齊卷名」，拆成卷「第一卷 卷名」與章「第N章 標題」。
- 目錄右鍵：選取這章的全部內容、剪下並貼到其他章前後、套用格式到這章、合併、連續編號、
  設為卷／章標題、標註為非章節、刪除。選到卷時照卷底下的章計算。
- 五種主題：簡約白、簡約藍、淺棕色、深色、純黑（右上角的主題選單，會記住上次的選擇）；介面可切換繁體或簡體中文。
- 尋找／取代（工具列「尋找取代」、Ctrl+F，或 Ctrl+H 直接到取代框），支援正則表達式：^、$ 對每一行的開頭結尾，
  取代可以用 `\1` 或 `$1` 代入擷取的群組。
  正則模式的輸入框旁邊有「＋」：行首、換行、數字、連續問號、A 開頭 B 結尾…點了插在游標的位置，選單不會關，可以連續組合。
  搜尋開著時改本文，結果不會清掉；下一個／上一個從游標的位置接著找。

### 內容檢查

- 工具列「內容檢查」卡片：掃描無關連內容、作者感言與作品資訊、標點校對、章節字數、繁簡轉換（全文或只轉選取的章節）。
- 章節字數：全書與每一章的字數，標出特別短（可能只剩作者的話）與特別長（可能兩章之間少了標題）的章。
- 按鈕下面的「顯示無關連內容字色」「顯示作者感言與作品資訊字色」兩個開關：照掃描視窗勾選的類型，
  用不同字色標在本文上（同一行兩種都是時用無關連內容的顏色，只影響顯示）；本文改過會在背景自動重新標示。
  顏色的意思寫在檔名列的「說明」（問號）裡。
- 同一張卡片的「顯示內文空格」：把半形／全形空格、Tab 畫出來，行尾多餘的空白標紅。
- 「顯示章節標記」「匯出時移除章節標記」：章節標記（[::] 這類，使用者手動標記並寫入本文，保存目錄的手動調整）
  要不要顯示、匯出時要不要拿掉。

### 標點校對

![標點校對，紅字是自動修正會改動的字](docs/screenshots/04-quote-check.png)

- 找出對話中途斷行、引號沒有成對、標點在行首、兩段對話黏在一起。
  整本是硬換行（句子被切成好幾行）的書，跨行成對的引號不列出，改提示先用「整理段落換行」接回去；
  沒有縮排、一段話分成好幾行（引號到最後一行才關）的書，這些也不列出，但不會叫你整理段落換行。
- 太長的分隔線（----------、*****…）縮成三個；連續的句號（。。。）、太長的刪節號、
  中文裡的半形點（...）改成標準的「……」，網址與英文不會動。
- 段落裡太長的破折號（——————、——-、中文裡的 ----）改成「——」，~~~~、～～～～ 改成「～」。
- 同一本書混用不同的分隔線（---、===、***）時，可以在「分隔線統一成」選一種，
  其他樣式的分隔線列出來、勾選後一起改；預設不統一。
- 有明確正確寫法的可以一鍵修正，「修正後」欄用紅字標出會改動的字。
- 對話框開著時可以直接在本文手動修改；切回對話框會自動重新檢查。

### 掃描無關連內容

![掃描無關連內容](docs/screenshots/05-ad-scan.png)

- 找出網址、下載頁、QQ／微信、小說來源，以及網頁轉存留下的字元碼（&#29368;、&nbsp;）與 HTML 標籤（<p>、<br>）；
  這些不是刪掉整行，而是換回原本的字、拿掉標籤。
- 夾在正文裡的網址廣告（同一段「網站名＋網址」出現在好幾行正文的結尾或中間）只刪那一段，正文留著；
  故事裡提到的網站、只提到「微信」「網站」的句子不列，章節標題也不會整行當成廣告。
- 「重複段落」獨立一個分頁：最短長度、至少重複幾次都可以拉拉桿或在數字框輸入，表格即時更新。
  整章、整本內容重複放了好幾次的（連續好幾行都是重複的）和狀聲詞不列，那是內容重複，不是廣告。
- 預覽欄照內容寬度顯示，段落很長時可以橫向捲動。點一列，表格下面顯示那一段加上前後各三行，
  找到的部分照本文字色標出來（標點校對用修正後的紅字）；中間的分隔可以拖動調高度。
- 「只掃描／只檢查選取的 N 章」每次打開都是關著（掃整本），要只處理選取的章節自己打開。
- 論壇轉貼留下的樓層資訊、使用者資料表、評分記錄也在這裡（「論壇轉貼資訊」）；帖子標頭後面那一行作者的閒聊
  （「求打賞」「今天先更這本」）列在作者感言。
- 「轉存遺失的字（??）」：轉存時表情符號變成的半形問號（段落開頭的「??」、整行只有「??」），拿掉問號、正文留著。
- 作者感言與作品資訊（作者、字數、發表平台、分隔線、章末的作者的話）在另一個視窗；
  檔案開頭第一章之前的書籍資訊不列入。章末一長串破折號（——————）後面的幾行短句也算作者的話（中信心）。
- 依信心高低分級，高信心預設勾選；點一列跳到本文那一行確認後再刪除。

### 辨識章節

![辨識章節：用積木組出標題的寫法](docs/screenshots/06-recognition.png)

- 章節管理的「辨識章節」：章、卷各一頁，用六欄積木組出標題的寫法——外框（( )、【 】）、前綴（第、#、Chapter、卷…）、
  數字（一二三、123、全形、壹貳參）、單位（章、回、話、卷、集、季…）、分隔（空格、、、.、：…）、章名（要有、可有可無、沒有）。
  同一欄可以選好幾個；上面的範例跟著最後點的積木變，下面寫出本文已收錄、未收錄幾行，「看本文的行」點一列跳到那一行。
- 內建的「第N章」「第N卷」就是自動辨識，只能開關單位（例如關掉「節」，「第三節 山路」這種小節就不會變成一章）。
- 「新增組合」可以從空白開始，或從常用寫法開始（照信心分成高、中、低：#1 標題、Chapter 1 是高；(1) 標題、1. 標題是中；
  只有數字的是低）；也可以貼一行標題，自動選好積木。組合可以自己命名，不改就照積木自動取名。
- 「2-1」「2-3 標題」這種卷號-章號的寫法（常用寫法「2-1 標題」）：前面是第幾卷（季）、後面才是章號。
  本文寫了「第二季」的，排版時底下的「2-1」寫成「第1章」；沒寫的照原樣留著，開「自動補齊卷號」會補一個「第二季」。
- 特殊標題（序章、楔子、後記、番外、外傳、終章、名稱＋篇…）可以各自關掉，或設成卷、章。
  也可以在「自訂」新增自己的字（例如「續章」）：「續章12」「書名 續章3」「續章：標題」都認得（簡繁兩種寫法），
  照原文顯示、排版不改寫成「第N章」；編號自己一組檢查缺章、重複。
- 底下的標題長度、章名結尾（哪些標點結尾的行仍然算標題）是所有辨識共用的設定。「第N章＋分隔＋章名」的正式寫法章名很長時放寬到 100 字
  （章名裡有句號、引號沒收尾的，是章名跟正文第一句黏在一起，照樣不算；標題長度調得比預設短時不放寬）。
  句號結尾的「第N章 章名。」：章號接得上上一章（或是第 1 章）、章名很短時照樣算一章。
- 目錄是空的或只收到零星幾章、最後一章之後換了寫法（例如從「第12章 標題」變成「13. 標題」）、
  書中間有一段換了寫法（目錄從第 628 章跳到第 700 章，中間是「629. 標題」），
  或是目錄沒有卷而本文有「卷一 卷名」，目錄卡片上方會提示：章號接得上的一鍵加成組合；
  接不上號的（例如「2-1」）打開本文可疑章節，只列那一種寫法。
- 開頭多了「正文」「VIP章節」的（「正文 001 標題」）、半形全形混寫的章號（「06４」），常用寫法與組合都認得。
- 常用寫法也認得少了「第」的「12章 標題」（單位後面要有空格或標點才接章名）。

### 自訂章節規則

- 自己寫的正則：貼上一行章節標題就能自動產生規則，不必懂正則。
- 「本文可疑章節」列出看起來像標題、但還沒進目錄的行，勾選後一次加入；常用寫法的整種格式可以直接加成辨識章節的組合。

## 從原始碼執行

```bash
python -m pip install PySide6 regex
python -m ui_qt
```

`regex` 讓自訂章節規則、尋找的正則有逾時保護（寫壞的正則不會讓程式卡住）。
選用套件：`opencc-python-reimplemented`（簡體介面、匯出檔名與正文的繁簡轉換）。

Windows 版 exe 在 GitHub 的 Releases 下載。

## 專案結構

```
core/       純邏輯，跟介面無關
  chapter_parse.py       單行章節標題辨識（預設只收正規格式）
  user_rules.py          自訂章節規則的比對
  title_blocks.py        辨識章節的積木（組合 → 規則）
  collection.py          多作品合集、未辨識章節候選、缺章檢查
  structure_builder.py   整份文件的章節結構／目錄樹建立
  ad_scan.py             無關連內容（廣告、網頁字元碼）與作品資訊掃描
  quote_check.py         標點校對
  reflow.py              硬換行／異常空白整理
  script_convert.py      繁簡轉換（OpenCC）
  persistence.py         自訂規則／視窗狀態存檔
  ...

ui_qt/      PySide6 介面
  main_window.py         主視窗
  *_dialog.py            各功能對話框
  find_bar.py            尋找／取代面板
  theme.py               色彩 token 與樣式表
  icons.py               內嵌 SVG 圖示
  app_log.py             記錄檔與卡死監看（Ctrl+Shift+L 開啟記錄檔資料夾）
```
